# Sentinel frontend

React and TypeScript dashboard with an Express API for voice-verified demo payments.

See [the project README](../README.md) for installation and [LOCAL_SETUP.md](LOCAL_SETUP.md) for the voice payment workflow and troubleshooting.

```powershell
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000. Live voice verification requires the parent project Python dependencies and DetectifAI configuration.
